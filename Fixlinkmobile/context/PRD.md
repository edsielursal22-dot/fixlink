# Product Requirements Document (PRD) — FixLink Mobile

## 1. Executive Summary
FixLink is a mobile platform connecting customers needing repair/maintenance services with qualified technicians.

## 2. User Roles & Capabilities
### Customer
- Register / Log in.
- Submit service/repair requests with details (title, description, location, photos/documents).
- View platform announcements and request status.

### Technician
- Register / Log in.
- Browse available service jobs.
- Accept / update status on jobs.
- View and manage technician profile and performance details.

## 3. Core Features
- **Authentication:** Role-based authentication (Customer vs. Technician).
- **Service Request Flow:** Request creation, media attachment, geolocation tagging.
- **Job Matching & Dispatch:** Available jobs feed for technicians based on service domain/location.
- **Notifications & Announcements:** Global announcements banner for platform updates.
